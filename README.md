CodeSync 🚀

Real-time collaborative code editor built with React, Monaco Editor, Socket.IO, and Node.js. Users can create shared coding rooms, join with a unique room ID, and collaborate on code in real time.

Features
🔥 Real-time collaborative code editing
👥 Multi-user room system
🎯 Unique room IDs for instant collaboration
📝 Monaco Editor integration (VS Code editor experience)
⚡ Socket.IO powered synchronization
🌐 React + Vite frontend
🚀 Express + Node.js backend
🎨 Modern dark-themed UI

How It Works
Create a room or join an existing room.
Share the generated Room ID with collaborators.
Multiple users join the same room.
Code changes are synchronized instantly using Socket.IO.
Active participants are displayed in the room sidebar.
